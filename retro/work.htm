component library & design system FEATURED
personal project · work in progress · 2024 to now

a framework-agnostic UI library i am building. web components are the single source of truth, with thin React bindings on top and a design-token layer that mirrors a familiar Material-style theme, so existing applications can adopt it without a rewrite.

108 components so far. coverage keeps growing, usage is documented in Storybook, and the packages ship through a private registry. the aim is one UI foundation that behaves the same in React, plain HTML and whatever comes next.
